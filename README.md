# 🏍️ BikeZone Showroom Website

A modern, responsive **Bike Showroom landing page** built using HTML and CSS.  
It showcases different bikes with a clean UI, hero section, and navigation bar.

---

## 📌 Features

- Responsive navigation bar
- Attractive hero section with background image
- Product (bike) showcase cards
- Hover animation effects
- Clean and modern UI design
- Simple and lightweight (only HTML + CSS)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (optional)
- Unsplash images
